## 🎯 核心洞察

Amazon 运营正在进入 AI Agent 时代。`amazon-seller-mcp`（⭐18）打通了 Claude/DeepSeek 等 AI 与 Amazon SP-API 的桥梁，意味着**用自然语言管理 Listing、库存、订单成为可能**。同时 SocioSell（⭐23）把社媒内容自动转成商品 Listing，展示了"流量→变现"的 AI 化路径。

关键数据点：
- Amazon 服饰品类佣金 17%（>$20）、5-10%（<$20）—— 低价服饰佣金大幅下降
- 消费电子 8%——最低费率品类
- 美妆/个护 8-15%——<$10 低费率

## 📊 详细分析

### Amazon Seller MCP — AI 原生运营平台

**核心能力：**
- 📦 **SP-API 全覆盖**：Catalog / Listings / Inventory / Orders / Reports 五大模块
- 🤖 **自然语言操作**：AI 可以直接查库存、改价格、优化 Listing、看报表
- 🛡️ **企业级安全**：OAuth 2.0、自动 token 刷新、限流
- 🌍 **全球市场**：US、EU、亚太、中东全覆盖
- 🧪 **代码质量**：99.9% 测试通过率（1686/1693）、82.4% 覆盖率

**与 NΞXUS 的关系：**
这个工具和 Hermes 正在做的知乎自动发布原理相同——都是 AI Agent 调用外部 API 完成业务操作。区别在于它针对的是 SP-API（卖家后台），Hermes 针对的是 CDP（浏览器前台）。

**技术栈：** TypeScript、SP-API、OAuth 2.0、MCP Protocol、Node >= 18

### SocioSell — 社媒到 Listing 的 AI 桥梁

**功能：** 用户上传社媒图片/视频 → Gemini AI 识别产品 → 自动生成 Amazon 风格的商品标题、五点描述、详情

**局限：** Gemini API 限制一次最多 5 张图、3 个视频（每个 <10s）

**价值启示：** 国内抖音/小红书种草内容可以直接转跨境电商 Listing，省掉翻译+写文案的人工。
