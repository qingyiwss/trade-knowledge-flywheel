# Amazon 全链路利润测算

## 🎯 核心洞察
**Amazon FBA 净利润率低于 25% 的产品不要做** — 隐性成本（退货、广告、仓储）常常吃掉账面利润的 30-40%。

关键数据：
- 平台佣金 15% + FBA 费 + 广告 8-12% + 退货 3-5% = 隐性成本约 30-35%
- 德国站 VAT 19% 由卖家代收代缴，定价时必须内嵌
- FOB $5 的产品，到 Amazon 到手价通常 $12-15 才有利润

## 📊 详细分析

### 成本拆解公式

```
营收 = 售价 × 数量
总成本 = 采购 + 头程运费 + 关税 + FBA费 + 平台佣金 + 广告 + 退货损耗 + VAT
净利润 = 营收 - 总成本
利润率 = 净利润 / 营收
盈亏平衡价 = 总成本 / 数量
```

### 各国关税参考（灯具类 HS 9405）
| 市场 | 关税 | VAT | 备注 |
|------|------|-----|------|
| 德国 | 4.5% | 19% | CE+RoHS+WEEE+包装法 |
| 美国 | 3% | 0% | FCC+UL认证 |
| 英国 | 5% | 20% | UKCA替代CE |
| 日本 | 0% | 10% | PSE认证 |

### 利润健康度标准
- **>25%** ✅ 健康，值得放量
- **15-25%** ⚠️ 偏低，提价或压成本
- **<15%** ❌ 危险，随时亏损

## 🔄 行动映射

1. **算账**：用 `profit_calc.py` 输入真实采购/运费/广告，看实际利润率
2. **定价**：目标价 = 盈亏平衡价 × 1.35（留充足利润空间）
3. **优化**：利润率 < 20% → 先谈采购降本，再考虑提价
