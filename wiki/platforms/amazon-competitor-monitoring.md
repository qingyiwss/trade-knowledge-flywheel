# Amazon 竞品监控与定价策略框架

## 🎯 核心洞察
**不监控竞品 = 闭着眼睛开车**。Amazon 的价格战永远不会停，你要做的是知道竞品在干什么，然后选择"不打价格战"的差异化路径。

关键数据：
- Amazon DE 灯具类 Top 10 的定价波动频率: 平均 3-5 天调整一次
- 价格下降 €1 → 竞品可能跟进时间: 24-48 小时
- Keepa 免费版足够监控 5-10 个 ASIN
- Helium 10 月费 $79（Platinum），是德国站卖家的标配

### 竞品分层监控法

选取 10 个直接竞品，分三层：

**第一层 — 头号竞品（2-3个）**：
- BSR 最接近你的
- 价格带重叠
- **每日监控**: 价格、BSR、促销、新变体

**第二层 — 类目标杆（2-3个）**：
- Top 3 BSR 产品
- 学习他们怎么做 listing/A+/图片
- **每周监控**: 策略性变化（新增 A+、改标题、上新变体）

**第三层 — 预警对象（4-5个）**：
- BSR 快速上升的新品
- 价格比你低 15%+ 的
- **每周监控**: BSR 趋势、价格变化

### 价格战应对决策树

```
竞品降价 5-10%
├── 你的 Review < 50? → 不跟!（用户选你是因为信任，不是价格）
├── 你的 Review 50-200? → 跟 50%（他降 €2，你降 €1）
└── 你的 Review > 200? → 不跟!（你有品牌护城河了）

竞品降价 > 15%
├── 是新上架的低价倾销? → 不理（他没利润撑不住，1-2月自然消失）
├── 是大牌清仓? → Coupon 开 €1-2（不直接降价，保护历史价格）
└── 是全类目价格战? → 做变体差异化（加功能/改组合/换包装）而不是降价
```

### 不要陷入价格战的三条出路

1. **变体差异化**: 
   - 竞品卖 36W → 你上 40W（参数碾压）
   - 竞品只白光 → 你主打 2700K-6500K 无极调光
   - 竞品单装 → 你做 2/4/6 个装（平均单价低，但客单价高）

2. **Bundle 组合**:
   - LED 面板 + 智能开关 + 安装配件 = "一站式套装"
   - 竞品没法比价，因为东西不一样

3. **品牌溢价积累**:
   - 竞品能抄你的产品，抄不了你的 500 条好评
   - 竞品能抄你的价格，抄不了你的 Stiftung Warentest "Gut"
   - 每多一个认证/好评 = 多一层护城河

### 竞品 Review 挖掘（金矿）

每周看 Top 3 竞品的最新差评（1-3星），提炼改进点：

```
竞品 A 差评:
"安装说明只有中文，德语客户看不懂"
→ 你的机会: 德语视频安装指南 + 德语说明书

竞品 B 差评:
"用了 3 个月就开始闪"
→ 你的机会: 强调 "50.000 Stunden getestet, 3 Jahre Garantie"

竞品 C 差评:
"亮度不够，和描述不符"
→ 你的机会: 标注真实 Lumenzahl + 场景图对比
```

## 🔄 行动映射

1. **装工具**：注册 Keepa（免费）+ Helium10（$79/月 或先用免费版），装好浏览器扩展
2. **建监控表**：选 10 个直接竞品 ASIN → 分层 → 在 Keepa 追踪

4. **降价决策前**：用上面的决策树，不要条件反射式跟价
