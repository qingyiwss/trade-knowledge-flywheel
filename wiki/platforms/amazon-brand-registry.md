# Amazon Brand Registry 商标注册与品牌备案指南

## 🎯 核心洞察

Brand Registry 不是可选项，是 Amazon 德国站运营的基础设施。没有 BR = 不能开 Vine、不能做 A+ 内容、不能创建品牌旗舰店、不能投品牌广告、防跟卖能力几乎为零。

关键数字：
- EU 商标注册费用：€850（EUIPO 官费，含一类商品/服务）+ 代理费约 ¥2,000-4,000
- 申请到拿证：4-6 个月（EUIPO 平均），快的话 3 个月
- 拿到商标号（R 标记前）即可申请 BR，不需要等纸质证书
- Amazon BR 审核时间：2-10 个工作日

## 📊 详细分析

### 第一步：注册 EU 商标

**选类目（关键）**：
- LED 灯具属于 **第 11 类**（照明设备）
- 如果卖灯具+智能控制 → 加 **第 9 类**（电子控制器）
- 如果做品牌配件 → 加 **第 20 类**（安装支架）

**注册渠道**：
1. **EUIPO 直申**（europa.eu）：最便宜但需要 EU 地址接收通知
2. **马德里国际注册**：中国商标局 → WIPO → 指定 EU，适合已有国内商标的
3. **代理机构**：报价 ¥5,000-10,000 全包，推荐。自己搞容易因"描述不清"被驳回，补正耽误 2-3 个月

**费用拆解**：
| 项目 | 费用 |
|------|------|
| EUIPO 申请费（1类） | €850 |
| 附加类 | €50/类 |
| 代理服务费 | ¥2,000-4,000 |
| **总计（1类，含代理）** | **约 ¥8,000-10,000** |

**时间线**：
1. 提交申请（Day 0）
2. EUIPO 形式审查（1-2 周）
3. 公告期（3 个月）
4. 无异议 → 注册完成（约 4 个月后）
5. 拿到注册号 → 可立即申请 BR
6. 正式证书（再 1-2 个月）

### 第二步：Amazon Brand Registry 申请

**前提条件**：
- 商标已注册或 pending（TM 标也可以，但功能受限）
- 商标类型必须是文字商标（Word Mark）或图文商标——纯图形商标不被接受
- 商标必须显示在你产品的包装上

**申请流程**：
1. Seller Central → 品牌 → Brand Registry → 注册新品牌
2. 填写商标名称 + 注册号 + 注册局（EUIPO）
3. 上传产品包装图片（必须清晰显示商标logo + 产品实物）
4. Amazon 发送验证码到商标注册时留的联系人邮箱
5. 回复验证码 → 完成备案

**⚠️ 避坑**：
- 包装图上的商标必须和申请表填的一模一样，否则被拒
- 商标注册联系人邮箱必须是你能收到的——Amazon 发验证码只发到那个邮箱
- 如果用了代理注册，确认代理给你的是"直接联系人"还是"代理律所"的邮箱——后者收不到 Amazon 验证码，需要联系代理转给你

### 第三步：BR 后续操作

| 功能 | 何时可用 |
|------|---------|
| A+ 内容 | BR 通过后立即 |
| Vine 计划 | BR 通过后立即 |
| 品牌旗舰店 | BR 通过后，需 1-2 天设置 |
| 品牌分析 | BR 通过后，数据 24-48 小时回填 |
| 品牌推广广告（SB） | BR 通过后立即 |
| 透明计划（防跟卖） | 需单独加入（免费），FRU 标签每件 $0.05 |

### TM 标 vs R 标

| | TM 标 | R 标 |
|---|------|------|
| 含义 | 已申请，正在公告 | 已正式注册 |
| 适用 | 所有功能 | 所有功能 + 更强法律保护 |
| 时间 | 提交后 1-2 周 | 4-6 个月 |
| BR 申请 | ✅ 可以，但不是所有类目都接受 | ✅ 全部接受 |

## 🔄 行动映射

1. **本周**：确定品牌名（建议 2 个备选，防止重名），找代理报价
2. **下月**：提交 EUIPO 申请
3. **拿到 TM 号后**：立即申请 BR（不要等 R 标）
4. **BR 通过当天**：设置 A+ 内容 + 开 Vine + 创建品牌旗舰店
5. **拿到 R 标后**：加入透明计划，贴 FRU 防跟卖标签
