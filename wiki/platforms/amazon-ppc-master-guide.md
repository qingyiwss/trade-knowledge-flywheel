# Amazon PPC 广告实战完全指南

## 🎯 核心洞察
**ACOS 不是越低越好 — 目标是 ACOS < 毛利率的 60%**。新品期 ACOS 30-40% 正常，成熟品应在 15-22%。德国站 CPC 约 €0.35-0.80（灯具类），低于美国站 20-30%。

关键数据：
- 健康 ACOS = 毛利率 × 0.5-0.6（毛利率 40% → ACOS 目标 20-24%）
- TACOS（总广告费/总营收）比 ACOS 更重要，目标 < 15%
- 德国站 Sponsored Products 占 80%+ 广告订单
- 自动广告的"搜索词报告"是最好的关键词挖掘工具

## 📊 详细分析

### 三种广告类型及适用场景

| 类型 | 展示位 | 适用阶段 | CPC(德国灯具) |
|------|--------|---------|-------------|
| Sponsored Products | 搜索结果+商品页 | 全阶段主力 | €0.35-0.65 |
| Sponsored Brands | 搜索结果顶部 | 品牌建设期 | €0.50-0.80 |
| Sponsored Display | 商品页+站外 | 再营销/防御 | €0.30-0.50 |

### 广告架构四层法

```
第一层：自动广告（发现）
  - 出价策略: 固定出价（新品）/ 仅降低（成熟品）
  - 预算: 每天 €10-15
  - 目的: 跑出搜索词 → 提取高转化词

第二层：手动精准（收割）
  - 把自动广告跑出的出单词做精准匹配
  - 出价比自动高 20-30%
  - N 周后表现好的词 → 第三层

第三层：手动广泛/短语（拓展）
  - 用精准词衍生出长尾词
  - 出价 = 精准的 60-80%

第四层：商品定位（防守+进攻）
  - 定位自己 ASIN（交叉销售）
  - 定位竞品 ASIN（抢流量）
  - 定位互补品类
```

### 关键词出价公式

```
初始出价 = 目标ACOS × 产品售价 × 预期转化率 

例: 售价€24.99, ACOS目标20%, 转化率预估8%
出价 = 0.20 × 24.99 × 0.08 = €0.40

调整: 曝光低 → 提价10-15% | 有点击无转化 → 降价或暂停
```

### 否定关键词策略

三种必加否定：
1. **品类否定**: "cheap", "free shipping", "wholesale"（找便宜货的不买品牌货）
2. **不相关否定**: 搜索报告里的无关词（如卖面板灯，"strip light"必须否掉）
3. **ASIN否定**: 竞品ASIN表现差 → 否定掉

### 德国站 PPC 特殊要点

- 德语关键词用 **Nominativ（主格）** 形式，不要用变格
- 德国消费者搜索偏好长尾词（"LED deckenleuchte 60x60 dimmbar warmweiß"）
- 欧洲站 VAT 不包含在广告费里，ACOS 计算用含税售价
- 德国站 B2B 客户占比高（~15-20%），可单独开 B2B 广告活动

## 🔄 行动映射

1. **上线第1周**：开一个自动广告（€10/天，固定出价 €0.50），跑 7 天出搜索词报告
2. **上线第2周**：提取 10-15 个出单词，开手动精准活动（出价€0.40-0.60），自动广告转为"仅降低"
3. **持续**：每周下载搜索词报告 → 加否定词 → 表现好的词提价 10% → 表现差的词砍掉
4. **月度**：检查 TACOS 趋势（应持续下降），如果 3 个月后 TACOS > 20% 要重新审视 listing 质量
