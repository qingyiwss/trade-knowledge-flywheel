## 🎯 核心洞察

2025-2026 年跨境电商最大的变量不是流量，是**合规成本**。EU GPSR 2024年12月已全面生效、EPR 覆盖品类持续扩大、墨西哥 RFC 新政要求 36% 预扣税。不合规的代价不再是警告信，而是直接下架、资金冻结。选品前先查合规已是必选项。

三个数据：
- EU GPSR 2024.12.13 起强制执行，没有缓冲期
- 墨西哥美客多 RFC 新政：不合规商品面临 **36% 预扣所得税 + 16% VAT**
- EPR 已从德国扩展到法国、西班牙、奥地利、意大利等 8 国

## 📊 详细分析

### 1. EU GPSR（通用产品安全法规）

**生效时间：** 2024年12月13日

**核心要求：**
- 在 EU 销售的所有非食品消费品必须有**欧盟负责人**（Authorized Representative）
- 产品必须标注制造商信息 + 欧盟负责人联系方式
- 必须提供产品安全信息（使用说明、警告标签等）
- 线上 Listing 必须展示上述信息

**影响的中国卖家：** 大量泛品类卖家（家居、玩具、电子配件）如果没有指定欧盟授权代表，Listing 可能被下架。

### 2. EPR（生产者责任延伸）持续扩展

**已覆盖国家：** DE, FR, ES, AT, IT, UK, SE, PL（8 国）
**已覆盖品类：** 包装、WEEE（电子废弃物）、电池、家具、纺织品、轮胎

**2025-2026 新变化：**
- 法国：纺织品 EPR 已生效，服装鞋帽卖家必须注册
- 西班牙：2025 年起包装 EPR 强制执行
- 意大利：2025 年起包装标签要求（需标材料代码 + 回收说明）

**成本影响：** 德国包装法注册 ~€150/年，WEEE ~€200-400/类目。如果做 3 个 EU 国家 + 3 个品类，合规成本轻松突破 **€2,000/年**。

### 3. 墨西哥 RFC（税务登记号）新政

**2025 年关键变化：** 美客多（Mercado Libre）要求所有卖家提供 RFC 税号

**惩罚力度：**
- 无 RFC = **36% 预扣所得税**（从订单款直接扣）
- 另叠加 16% IVA（增值税）
- 资金冻结至提供有效 RFC

**对中国卖家的影响：** 做美客多的必须注册墨西哥本土 RFC（通过当地代理），不能再用中国公司直接发货。

### 4. Amazon 自有合规工具

- **Account Health Rating (AHR)**：评分低于 200 = 有封号风险
- **Transparency Program**：防跟卖 + 产品溯源
- **Climate Pledge Friendly**：符合 EU 碳关税趋势的绿色标签

### 合规成本速算表（单个 EU 市场）

| 项目 | 年成本（€） |
|------|-----------|
| 欧盟授权代表 | 150-500 |
| 包装 EPR（DE） | 150-200 |
| WEEE（电子类） | 200-400 |
| CE/UKCA 检测 | 500-3,000/产品 |
| GPSR 合规更新 | 100-300/Li |

**总计：** 做欧盟站，一个品类起步合规成本约 **€1,000-4,500/年**。

## 🔄 行动映射

1. **立即检查**：已在售的产品是否满足 GPSR（有欧盟负责人？Listing 展示安全信息了吗？）→ 不满足的优先补
2. **选品阶段加入合规筛查**：新品类上线前，先查目标市场是否需要 EPR/WEEE/特殊认证。把合规成本计入 Unit Economics
3. **监控墨西哥机会**：美客多 RFC 门槛挡住大量不合规卖家 = 筛选后竞争降低。注册 RFC 的卖家可能是蓝海
