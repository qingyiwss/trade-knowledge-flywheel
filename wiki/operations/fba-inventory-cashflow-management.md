# FBA 库存与现金流管理

## 🎯 核心洞察
**断货 3 天 = 排名掉 20-30 位 = 恢复需要 2-4 周**。过度压货又吃现金流。库存管理的艺术是在断货风险和资金效率之间走钢丝。

关键数据：
- FBA 库存周转健康线: 30-60 天
- IPI 阈值: 400（低于 400 = 仓储限制 + 超额仓储费）
- 长期仓储费: 存放 > 180 天触发（$1.50/cuft），> 365 天加倍
- 缺货成本: 每次断货损失约 7 天正常销量的利润（因为排名恢复期）

## 📊 详细分析

### 库存健康指标

| 指标 | 公式 | 绿灯 | 黄灯 | 红灯 |
|------|------|------|------|------|
| 库存天数 | 库存量 / 日均销量 | 30-60天 | 15-29天 | <15天 |
| 售罄率 | 已售 / (已售+在库) | > 70% | 50-70% | < 50% |
| 库销比 | 库存 / 月均销量 | 1-2 | 2-3 | >3 |
| IPI 分数 | Amazon 计算 | > 500 | 400-500 | < 400 |

### 补货计算公式

```
安全库存 = 日均销量 × (采购提前期 + 运输天数 + 缓冲天数)

例: 日均销 10件, 采购 14天, 海运 30天, 入仓 5天, 缓冲 15天
安全库存 = 10 × (14+30+5+15) = 10 × 64 = 640件

补货点 = 日均销量 × (采购提前期 + 运输天数 + 入仓天数) + 安全库存
       = 10 × (14+30+5) + 100（最低缓冲）
       = 490 + 100 = 590件

当库存 < 590件 → 触发下单
```

### 头程物流选择

| 方式 | 时效 | 成本（¥/kg） | 适用 |
|------|------|------------|------|
| 海运整柜 | 30-40天 | ¥8-12 | 大批量(>10CBM) |
| 海运拼柜 | 30-40天 | ¥12-18 | 常规补货 |
| 铁路 | 18-22天 | ¥15-22 | 中等时效 |
| 空运 | 5-10天 | ¥28-40 | 紧急补货 |
| 快递(UPS/DHL) | 3-7天 | ¥35-55 | 断货危机 |

**建议组合**: 70% 海运 + 20% 铁路 + 10% 空运（应对突发）

### 现金流模型（单 SKU）

```
时间线: 下单 → 海运 → 入仓 → 开售 → 回款

T+0:   付定金 30%（采购）         -¥10,500
T+14:  付尾款 70%                 -¥24,500
T+14:  付运费                      -¥3,000
T+44:  货到德国 FBA 仓
T+45:  开始销售
T+52:  第一笔回款（Amazon 14天结算）
T+60:  完整回款周期

总占用: ¥38,000, 占用 52-60 天
回款后：收入 ¥52,000（按 40% 毛利）→ 净赚 ¥14,000

所以做 FBA 的本质是:
用 5-8万资金占用 2个月 → 获得 1-2万利润
年化回报率 = 100-150%（比基金高得多，但有库存风险）
```

### 多头程补货节奏

避免"一次性大货 → 断货"的锯齿模型，用滚动补货：

```
第1周:  100件 空运测款
第3周:  根据空运数据，下单 300件（海运）
第5周:  空运快卖完了 → 补 100件（铁路）
第8周:  300件海运到仓
第10周: 基本稳定 → 下单 500件（海运）
第13周: 500件 + 100件（铁路）接力

这样永远有货在海上/铁路上，避免断档
```

### 库存健康度周检清单

```
[ ] 可售库存天数: 是否在 30-60 天？
[ ] 预留库存: 有没有大量在转运中的？
[ ] 不可售库存: 退货/损坏 → 立即创建移除订单
[ ] 超龄库存: >180 天的 → 降价清仓或移除
[ ] 补货建议: Amazon 补货建议有没跟进？
[ ] 在途库存: 海运/铁路的货物 ETA 是否正常？
[ ] IPI 分数: 是否 > 400？
[ ] 仓储限制: 下一季度是否可能被限？
```

## 🔄 行动映射

1. **建补货模型**：用上面的公式填 Excel → 每次打开 Seller Central 对照看
2. **多线程补货**：首批空运 50-100 件测款 → 下单 300-500 海运 → 稳定后滚动 500 件/月
3. **现金流预算**：永远保证账户有 2 个月的采购+运费资金，不要把所有钱压在货里
4. **每周检查**：每周固定时间做上面的周检清单，防断货于未然
