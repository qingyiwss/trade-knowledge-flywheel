# 1688 供应商谈判与采购实战手册

## 🎯 核心洞察
**1688 的定价空间是报价的 15-25%** — 不要接受第一个报价。同一产品至少比 3 家，选"中等规模 + 有出口经验"的工厂，避开纯贸易商。

关键数据：
- 1688 商家 80% 是贸易商/二道贩子，真正工厂不到 20%
- 第一批货的合理采购量 = MOQ × 1.5-2.0（不要一上来就大单）
- 1688 价格一般是 FOB 价格的 40-60%（因为不含出口退税/认证/包装）
- 验货费 ¥500-1,500/次，防止整批报废

## 📊 详细分析

### 如何识别工厂 vs 贸易商

| 信号 | 工厂 ✅ | 贸易商 ❌ |
|------|---------|----------|
| 店铺名 | "XX市XX电子厂" | "XX商贸"/"XX电子商务" |
| 产品图 | 车间实拍、有瑕疵的 | 精修、统一风格 |
| 起订量 | 灵活可谈 | 死板不松口 |
| 技术问答 | 能回答 PCB/灯珠等细节 | 只会背参数 |
| 实地视频 | 愿意视频看厂 | 找借口推脱 |
| 资质 | 有 ISO/BSCI/验厂报告 | 拿别人的证 |

### 谈判话术框架

**第一轮（询盘）**：
> "你好，我这边做德国 Amazon 的，月销 200-300 件，增长中。这款 60x60 LED 面板灯报个价，要 **CE+RoHS 版本**，含包装。"

**要点**：
- 说明目标市场（德国 = 高标准，工厂不敢糊弄）
- 报真实但不夸张的体量（太大会被觉得在吹牛，太小不被重视）
- 明确认证要求（筛掉没证的贸易商）

**第二轮（砍价）**：
> "A 工厂报价 ¥32.5，你们 ¥38 有点高了。如果能到 ¥33 我先下 100 件试单，后面稳定月 300+。"

**要点**：
- 永远有"对手报价"（不要说名字）
- 用试单换价格
- 价格 + 数量一起谈

### 1688 采购成本拆解（以 LED 面板灯为例）

```
工厂报价: ¥35/件（含包装）
+ 1688平台费: ¥0（买家端免费，开票加 1-3%）
+ 国内运费: ¥200-400/批（到义乌/深圳货代仓）
+ 验货费: ¥800-1,200/次（第三方，如 SGS/TUV）
+ 贴标/换包装: ¥1-2/件（如需德语说明书/CE标）
≈ 实际采购成本: ¥36-38/件

如果是贸易商报价 ¥38 → 实际工厂价可能在 ¥30-32
```

### 品控三关

1. **首样确认**（下单前）
   - 要求寄 2 件大货样（不是样品间的"完美样"）
   - 检测：色温（2700-3000K）、亮度、功率、频闪
   - 留存 1 件做"封样"，收货时对比

2. **产中抽检**（生产到 30-50% 时）
   - 第三方验货（¥800-1,500）
   - 抽检数量 = √N（100件抽10件）
   - 不合格率 > 5% → 要求全检或拒收

3. **出货前全检/抽检**
   - 亲自或第三方验
   - 重点：标贴一致性、数量准确、外观无刮花

### 付款节奏

```
30% 定金（签合同/下单）
60% 发货前（验货合格后）
10% 收货后 30 天内（质量保证期）
```

⚠️ **绝对不要**: 100% 预付、微信转账、私人账户收款。

## 🔄 行动映射

1. **选供应商**：1688 搜 "LED面板灯 60x60 CE"，按销量排序，选前 5 家看起来像工厂的
2. **比价**：用"德国 Amazon 月销200+"的定位询盘，收到报价后至少压 10-15%，锁定 2 家备选
3. **下试单**：选最优 1 家，下 100 件试单（30% 定金），安排第三方验货
