# EU VAT / OSS / IOSS 实操指南

## 🎯 核心洞察
**OSS 是跨境卖家的税务救命稻草** — 不用在每个 EU 国家注册 VAT，只需在一个国家申报全 EU 的 B2C 销售。但 OSS 不覆盖仓储所在国的 VAT，所以 FBA 卖家必须注册仓储国 VAT。

关键数据：
- OSS 统一申报门槛: €10,000/年（全 EU 远程销售合计）
- 德国 VAT 标准税率: 19%（大多数品类），优惠税率: 7%（书籍/食品等）
- IOSS 适用: 货值 ≤ €150 的进口商品
- 德国 VAT 申报: 月报（年销售额 > €7,500）或季报（< €7,500）

## 📊 详细分析

### 三种 VAT 申报机制对比

| 机制 | 适用场景 | 申报国 | 税率 |
|------|---------|--------|------|
| **本国 VAT** | FBA 仓储所在国销售 | 仓储国 | 仓储国税率 |
| **OSS (One-Stop Shop)** | 从仓储国卖到其他 EU 国的 B2C | 仓储国（统一申报） | 目的地国税率 |
| **IOSS (Import OSS)** | 从中国直发 ≤€150 的货 | 任一 EU 国 | 目的地国税率 |

### 你的场景：德国 FBA → 全 EU 销售

**必须注册**:
- 🇩🇪 德国 VAT（因为 FBA 仓在德国）— 本地销售用
- 🇩🇪 德国 OSS — 跨境销售到其他 EU 国用

**不必注册（用 OSS 覆盖）**:
- 法国/意大利/西班牙 VAT（除非你单独在那些国家设仓）

### 德国 VAT 注册流程

```
1. 准备材料:
   - 营业执照（翻译公证）
   - 法人护照
   - Amazon 店铺链接
   - 德国税务授权书（必须德语）
   
2. 申请税号:
   - 先拿 Steuernummer（税号）→ 约 2-4 周
   - 再拿 VAT-ID（DE 开头）→ 再 2-4 周
   - 全程约 4-8 周

3. 费用:
   - 自行注册: €0（但德语沟通门槛高）
   - 税务代理: €300-500/月（含申报）
   - 首年总成本: ~€3,600-6,000

⚠️ 不要用网上"¥999 包注册德国 VAT"的服务 — 后续出了问题找不到人
```

### VAT 计算示例

```
场景: 从德国 FBA 卖 LED 面板灯到法国消费者

售价: €24.99
成本: €12（采购+运费+FBA）

德国 VAT(19%) 申报:
  销项税: €24.99 × 19% = €4.75
  进项税: €12 × 19% = €2.28（可抵扣）
  应交: €4.75 - €2.28 = €2.47

法国 OSS 申报（税率 20%）:
  法国 VAT: €24.99 × 20% = €5.00
  但 OSS 下只需在德国申报法国 VAT
  实际交给德国的税务: 德国本地 VAT + 法国 OSS VAT

⚠️ 定价必须含 VAT! 德国站前台价格 = 含税价
   你的实收 = 售价 / (1+税率)
   €24.99 / 1.19 = €21.00（你的到手价）
```

### IOSS 使用场景（中国直发 ≤€150）

如果你从中国直发 ≤€150 的货到 EU 消费者：
```
优点: 消费者结账时就付 VAT，不需要到货时跑去海关交税
缺点: 需要注册 IOSS（有月费）
适用: 独立站/小件测款
```

但对于 FBA 卖家，IOSS 基本用不到（货已经在德国仓了）。

### OSS 申报实操

**什么时候用 OSS**:
1. 你的货在德国 FBA 仓
2. 德国消费者买 → 用德国 VAT 申报
3. 法国/意大利/西班牙消费者买 → 用 OSS 申报（在德国统一报）

**申报频率**: 季度（季末次月 20 日前）

**申报内容**:
```
国家 | 销售额(€) | 税率 | VAT
法国 | 2,000     | 20%  | €400
意大利 | 1,500   | 22%  | €330
西班牙 | 800     | 21%  | €168
合计 | 4,300     | -    | €898
```

### 常见罚款

| 违规 | 罚款 |
|------|------|
| 未注册 VAT 就开售 | 补税 + 销售额 10-20% 罚款 |
| 延迟申报 | €50-500/月 |
| 晚缴税款 | 利息 1%/月 |
| 包装法未注册 | €1,000-10,000 |
| WEEE 未注册 | €5,000-50,000 |

## 🔄 行动映射

1. **注册 VAT**：找德国税务代理（推荐 Avalara / Taxdoo / 当地华人会计所），不要贪便宜用 ¥999 服务
2. **注册 OSS**：VAT 下来后，在德国 Finanzamt 激活 OSS 申报（VAT 代理可以代办）
3. **定价含税**：售价 = 目标到手价 × (1+税率)，如目标到手 €21 → 售价 €24.99
4. **合规先行**：上架前确保 WEEE + 包装法 + VAT 三证齐全，不要在"先卖再说"上赌
