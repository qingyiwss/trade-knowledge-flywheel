## 五、操作流程（6 步）

### 第 1 步：跑工厂拿样品（1 天）🆓

```
石家庄 → 青县美妆产业园（自驾 2.5h / 高铁到沧州+打车）
```

| 要做的事 | 工具 |
|------|------|
| 进 3-5 家厂看样品间 | 1688 先搜"沧州化妆刷工厂"锁定目标 |
| 每厂拿 2-3 套样品（入门套+专业套） | 不要空手走，样品就是以后的拍照素材 |
| 问清：MOQ（起订量）、OEM 是否做、交期、FOB 价 | 笔记本记下 |
| 加微信，拍照工厂车间 | 以后独立站"关于我们"用 |

> **话术**："我是做中东外贸的，想做 OEM 贴牌，先看样品。量起来后稳定翻单。"

### 第 2 步：定品 + 定包装（1-2 周）

```
确定 2 个 SKU → 设计品牌名 + logo → 定制包装
```

| 决策 | 建议 |
|------|------|
| 刷毛 | **仿生纤维毛**（便宜+纯素趋势+无动物实验争议） |
| 刷杆 | 桦木/ABS 塑料（不要金属杆——海运易生锈） |
| 套刷支数 | 入门套 8 支、专业套 12 支 |
| 品牌名 | 3-5 个字母的英文名，好记、无负面含义 |
| 包装 | 纸盒+磁吸翻盖（比塑料高档，比铁盒便宜） |

> ⚠️ 包装盒必须标注：品牌名、支数、刷毛材质、"Made in China"、条形码

### 第 3 步：SFDA 注册 + 标签合规（2-3 周）

化妆刷属于 **美容工具**（非化妆品），认证比护肤品简单：

| 要做 | 怎么搞 |
|------|------|
| SFDA 产品注册 | 找认证代理 ¥2,000-3,000 代办 |
| 阿拉伯语标签 | 产品名、材质、产地、使用方法 → 翻译后印在包装上 |
| 条形码 | 淘宝买 EAN-13 条码 ¥10-50/个 |

### 第 4 步：独立站上线（1 天）

之前建好的沙特独立站框架，把化妆刷替换进去：

| 页面 | 内容 |
|------|------|
| 首页 | 品牌故事 + 产品图 + "沧州制造，沙特专供" |
| 产品页 | 2 个 SKU，多角度实拍图 + 规格表 |
| 关于 | 沧州青县工厂实拍 + 产业带介绍 |
| 联系 | WhatsApp + 邮箱 + 表单 |

### 第 5 步：社媒获客（持续）

| 平台 | 做什么 | 频率 |
|------|------|------|
| **LinkedIn** | 加沙特美容批发商/分销商 | 每天加 15-20 人 |
| **Instagram** | 发产品图+使用视频（阿语字幕） | 每周 3-4 条 |
| **TikTok** | 化妆刷使用教程（15-30 秒） | 每周 2-3 条 |
| **WhatsApp** | 客户转到 WhatsApp 谈 | 即时回复 |

### 第 6 步：试单发货

```
客户确认订单（50-100 套试水）
    ↓
收 30% 定金（TT 电汇 / PayPal）
    ↓
工厂生产（7-15 天，看是否有现货）
    ↓
发天津港 FOB
    ↓
货代安排海运 → 达曼港（20-25 天）
    ↓
客户付尾款 → 放单
```
