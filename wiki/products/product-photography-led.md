# LED灯具类目产品摄影规范

## 🎯 核心洞察

德国消费者对产品图的审美标准全球最高——他们看产品图判断质量，而不是看描述。LED 灯具类目的第一张主图直接决定点击率，白底图规范比美国和日本都严格。6 张副图需要覆盖"技术规格→使用场景→安装过程→效果对比"四个维度。

关键数字：
- 一张专业级 LED 灯具主图拍摄成本 ¥800-2,000/张（自己拍能压到 0）
- 德国站 LED 类目平均主图 CTR：好的 0.8-1.2%，差的 0.2%
- 有场景图（应用场景实拍）的产品，转化率高 40-60%

## 📊 详细分析

### Amazon 德国站图片技术规范

| 要求 | 规定 |
|------|------|
| 主图格式 | JPEG, TIFF, PNG |
| 主图背景 | 纯白 RGB(255,255,255) |
| 最小分辨率 | 1000 x 1000 像素 |
| 推荐尺寸 | 2000 x 2000 像素（支持缩放） |
| 主图内容 | 仅产品本身，无水印，无文字，无边框 |
| 产品占比 | 填满图像的 85% 以上 |

### LED 灯具 7 张图的标准结构

#### 主图（Hero）：纯白底产品正面

- 45° 角俯拍或正前方平拍
- LED 面板灯：开灯状态，光效均匀
- 绝对不要用手持有——用细丝悬挂或用透明支架
- 图片名格式：`brand-LED-panel-45x45-white.jpg`

#### 副图 1：尺寸/规格标注

- 产品 + 标注线 + 德文尺寸（单位 cm）
- 例：Aufbauhöhe: 2.5cm, Fläche: 60x60cm, Gewicht: 1.2kg
- 蓝色或橙色标注线比黑色更醒目

#### 副图 2：光效对比

- 左：普通照明 / 右：此产品照明
- 必须同一场景同一角度
- 用相机手动模式固定曝光参数——自动曝光会让光效看不出差异
- 德国人信任"数据对比"：标注 lux 值、色温 K、显色指数 CRI > 90

#### 副图 3：应用场景（🌟 德国站权重最高）

- 真实家居场景：现代简约风格（不是北欧花哨风）
- 深色木地板 + 白墙 + 极简家具 = 德国中产标配
- 建议场景：客厅天花板嵌入、厨房操作台上方、办公室工位
- ⚠️ 不要用 AI 生成场景图——德国消费者能识别，且可能被 Amazon 下架

#### 副图 4：安装过程

- 分步骤图示（4-6 步）
- 每步配德文短语（不是整句）
- 例：Schritt 1: Halterung an Decke befestigen / Schritt 2: LED-Panel einclipsen
- 安装工具展示：螺丝刀型号、钻头直径

#### 副图 5：能效/认证标签

- EU 能效标签（A-G 等级）
- CE 认证标志
- 德国 WEEE 注册号（WEEE-Reg.-Nr. DE XXXXXXXX）
- 质保说明：3 Jahre Garantie

#### 副图 6：视频（强烈推荐）

- 15-30 秒
- 内容：安装全过程 + 开灯效果 + 调光演示（如果有）
- 手机 + 三脚架即可，不需要专业设备
- 上传到 Seller Central 而非外部链接

### 自己拍 vs 找摄影师

| | DIY | 摄影师 |
|---|-----|--------|
| 费用 | ¥0 + 时间 | ¥3,000-8,000 全套 |
| 设备门槛 | iPhone 14+ + 柔光箱 + 白背景纸（¥150 总投入） | 专业设备 |
| 时间 | 3-5 天（含试错） | 1-3 天交付 |
| 德国审美把握 | 需要多看竞品图学习 | 交给懂欧美审美的 |
| 适合 | 预算有限、SKU 少（<5） | 预算充足、快速上线 |

### DIY 拍摄清单（¥150 投入）

1. **柔光箱**：60x60cm，¥50（淘宝）
2. **白色 PVC 背景板**：80x120cm，¥30
3. **手机支架**：三脚架 ¥40
4. **反光板**：折叠 5 合 1，¥30
5. **修图**：Snapseed（免费）调白平衡+曝光

拍摄环境：白天窗边自然光 + 柔光箱补光。色温 5500K。
