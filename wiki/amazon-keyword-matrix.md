# 关键词矩阵：搜索量 × 竞争度 × 转化率

## 🎯 核心洞察
**先打长尾蓝海词（低竞争+高意图），排名起来后再攻大词** — 直接抢大词 = 烧钱无转化。

关键数据：
- 购买意图=5 的精准词转化率是泛词的 3-8 倍
- 低竞争词（竞争度 1-3）CPC 通常是大词的 1/3
- 德语站长尾词机会远多于英语站（竞品少、翻译差）

## 📊 详细分析

### 机会分公式
```
机会分 = (月搜索量 × 购买意图) / (竞争度 × CPC × 10)
机会分 > 80 → 🔥 立刻打（放标题+精准广告）
机会分 50-80 → ⭐ 培育中（放五点/A+自然排名）
机会分 < 50 → 观望（先不烧钱）
```

### 广告阶段策略
1. **第1周**：自动广告 + 10个长尾精准手动
2. **第2周**：否掉无转化词，加 bid 到高转化词
3. **第3-4周**：有 5+ 评论后开大词手动广告
